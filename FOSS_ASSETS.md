# FOSS / CC0 asset register

The repository is designed around assets that can be redistributed from public sources with explicit permissive licensing.

| Source | License | Intended use |
| --- | --- | --- |
| Kenney Assets | CC0 / public domain | UI, environment, props |
| OpenGameArt — CC0 3D Characters | CC0 | player / NPC replacements |
| OpenGameArt — 3D Assets (CC0) | CC0 | environment / props |
| OpenGameArt — 3D Character Pack | CC0 | humanoid replacement |

The current player is an original procedural model and therefore has no third-party character asset dependency.

References:
- https://kenney.nl/support
- https://opengameart.org/content/cc0-3d-characters
- https://opengameart.org/content/3d-assets-cc0
- https://opengameart.org/content/3d-character-pack

When adding an asset, record its exact source URL, title, author and license here. Never import Mixamo or other non-FOSS content into this repository without an explicit licensing review.
